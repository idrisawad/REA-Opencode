## Contributing

1. Fork and create a feature branch: `git checkout -b feature/my-change`.
2. Keep the skill and its references in sync with upstream
   [morluto/rea](https://github.com/morluto/rea) when you change REA-facing
   content — note the upstream commit or skill `metadata.version` you synced from.
3. Bump `version` in [`index.json`](index.json) whenever any skill file
   changes, so OpenCode refreshes its cache.
4. Open a pull request describing the change and how you verified it
   (skill loads, REA tools appear, target analyzed).
